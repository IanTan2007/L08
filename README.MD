
# GetABoat

GetABoat is a mobile application that displays a catalogue of five different boats, including their names, descriptions and images.

For Lesson 08, I improved the application's visual appearance using React Native StyleSheet and Flexbox. The redesigned app features a nautical theme with an ocean background, rounded boat cards, custom fonts, cyan anchor icons and improved spacing and alignment.

The reusable Boat component ensures that all five boats have a consistent design.
